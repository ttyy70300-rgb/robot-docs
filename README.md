## 系统概览

```
┌──────────── 上位机（笔记本 · WSL2 Ubuntu 22.04 + ROS2 Humble）────────────┐
│  slam_toolbox │ Nav2 │ YOLOv8 │ sherpa-onnx │ FastAPI │ Vue 3 (Web/PWA)    │
└──────▲──────────────▲──────────────▲──────────────▲───────────────────────┘
       │ UDP 8888     │ UDP 8889     │ UDP 8891     │ UDP 8892
┌──────┴──────┐ ┌─────┴──────┐ ┌─────┴──────┐ ┌────┴───────┐
│ 板1 · 主控   │ │ 板2 · 感知  │ │ 板3 · 音频  │ │  （星型）   │
│ 电机闭环100Hz│ │ OV2640+雷达 │ │ PDM+I2S    │ │            │
└─────────────┘ └────────────┘ └────────────┘ └────────────┘
```

**三条不能破的约束**

1. 三块 ESP32-S3 各自连 WiFi，**星型直连上位机**，板间不通信
2. 设备面用 X-Protocol/UDP，客户面用 JSON/WebSocket，**中间由 `web_gateway` 翻译**
3. 一块模块坏了不能拖垮其他模块（见 `14`）

## 版本

**当前版本：v1.0（2026-11-08）· 正式发布版**

17 份文档统一为 v1.0，仓库 tag 与文档内部版本号一一对应。

### 本版包含的内容

一次到位，包含三个层次的完整内容：

**① 硬件梳理**（`00`~`12`）

三块 ESP32-S3 的分工、25 个 GPIO 的完整分配、12 类外设的接口与时序、以及所有厂商资料里藏着的坑（比如编码器分辨率写死 1560 而实际是 2496、INA226 的 100mΩ 采样电阻量程只有 0.8A）。

**② 软件架构**（`13`~`15`）

L1 设备面（X-Protocol/UDP）与 L2 客户面（JSON/WebSocket）两层协议、35 个模块的职责与接口、模块化与故障隔离的"开发宪法"。

**③ 开发环境**（`16`）

这台机器的完整软件清单与实测记录，包含一个关键突破：**GTX 950M 在 WSL2 里可用**，torch 2.1.2+cu118 跑通 sm_50。

### 评审后的 10 项修订

本版在初稿基础上解决了一批**会让 AI 生成的代码直接撞墙**的矛盾。

**5 项阻塞矛盾**

| # | 问题 | 结论 | 涉及文档 |
|---|---|---|---|
| 1 | PlatformIO 版本矛盾：`espressif32@6.9.0` 带的是 core 2.0.x，**没有 `ledcAttach`**，照抄必编译失败 | 改为 **`8.0.0`**（core 3.3.12），并实测编译验证 | `00` §12.1 |
| 2 | `0x50` 无 `seq`，但多处要求"序号去重"——序号无处安放 | **加 1 字节 seq**，6 B → 7 B；补 255→0 回绕规则 | `00` `02` `13` `15` |
| 3 | 里程计位姿两处积分（板 1 与上位机），必然漂移不一致 | **`0x10` 扩为 17 B 带位姿**，定案板 1 为唯一积分源 | `00` `02` `15` |
| 4 | `01` 是语音上移前的残留：`task_audio`、`0x14`/`0x53` 旧语义、优先级冲突 | 全面修订，`task_ctrl` 优先级 10 → 12 | `01` |
| 5 | `04` STBY 状态矛盾，且语义缺失（拉低是滑行不是刹车） | **GPIO47 受控**；急停必须 `AIN1=AIN2=H` 刹车后再拉低 STBY | `00` `01` `04` `05` `13` |

**5 项建议改进**

| # | 内容 | 结论 | 涉及文档 |
|---|---|---|---|
| 9 | `13` 的"独显/950M 验证"已被实测覆盖 | 标注**已完成**，附实测数据，方案 B 不启用 | `13` §10.4、§14 |
| 10 | OTA 分区表未经编译验证 | **实编译验证**：16MB + qio_opi + 自定义 CSV，`gen_esp32part.py` 反解逐字节一致 | `01` §5、`16` §8.1 |
| 11 | 板 3 单 I2S0 全双工的采样率约束未写明 | 写入：**PDM RX 与 I2S TX 必须同为 16 kHz** | `10` §4.2、`15` M21 |
| 12 | 局域网 UDP 完全无鉴权，同 WiFi 任何设备可开车 | 进风险表 **R20**，给出源 IP 白名单等低成本对策 | `00` §9、`15` M18 |
| 13 | 小项：`uptime` 回绕、版本号仅 8 位、引脚无预留、WDT 偏长 | `uptime`→uint32；版本→3 字节语义版本；GPIO2/41/48 标为可牺牲；WDT 10s→5s | `00` `01` |

### ⚠️ 协议变更（不向后兼容）

固件与上位机必须同步按此实现：

| 帧 | 初稿 | **v1.0** | 原因 |
|---|---|---|---|
| `0x10` | 6 B（纯速度） | **17 B**（seq + 速度 + 位姿 x/y/θ） | 位姿需要传输通道 |
| `0x13` | 12 B | **16 B**（`uptime` uint16→uint32，版本→3 字节） | 原 18.2 小时回绕；版本号 8 位不够 |
| `0x50` | 6 B（纯速度） | **7 B**（seq + 速度） | UDP 乱序时旧指令会覆盖新指令 |

变更明细见各文档内的「变更记录」章节与 git 提交历史。
