# 设备说明：INA226 电压电流检测模块

> 项目：ESP32-S3 两轮差速 ROS2 智能小车
> 文档版本：**v1.0**　｜　正式发布版
> 生成日期：2026-11-07
> 资料目录：`9-INA226模块/`

## 1. 设备概述

| 项目 | 内容 |
|---|---|
| 芯片 | **INA226**（TI，电流/功率监控器） |
| 接口 | **I2C / SMBus，最高 400kHz** |
| I2C 地址 | **0x40**（默认，7 位）；可配 4 档 |
| 共模电压范围 | **0 ~ 36V** |
| 供电 | 2.7 ~ 5.5V（典型 3.3V，330µA） |
| ADC | 12 位，电压分辨率 1.25mV |
| 采样电阻 | **板载 R3 = 100 mΩ（0.1Ω）** |
| 接口端子 | KF301-2P（5.0mm 螺丝端子），IN+/IN- |

---

## 2. ⚠️ 关键限制：量程只有 ±0.8A

### 2.1 数据推导

INA226 的**分流电压满量程为 ±81.92 mV**。

```
最大可测电流 = 81.92 mV / 100 mΩ = 0.8192 A
```

**官方 Arduino 例程印证**：

```c
#define R_SHUNT  0.1f      // 100 mΩ
#define I_MAX    0.8f      // 0.8A
ina.calibrate(R_SHUNT, I_MAX);
```

### 2.2 对本项目的影响

| 场景 | 电流 | 是否可测 |
|---|---|---|
| 静态（ESP32+屏+雷达） | ~0.7 A @5V | ⚠️ 接近满量程 |
| 电机启动峰值 | 2.4 A | ❌ 超量程，读数饱和 |
| 双舵机堵转 | 1.5 A | ❌ 超量程 |
| 整车主回路 | 1~3 A | ❌ **不可用** |

### 2.3 额外风险：功耗与压降

```
100mΩ 采样电阻在 3A 时：
  压降 = 3 × 0.1 = 0.3 V   （7.4V 系统的 4%，显著）
  功耗 = 3² × 0.1 = 0.9 W  （2512 封装额定 1W，会发烫）
```

> **结论：绝不能把 INA226 串在电池主回路**。

---

## 3. 三种可行方案

### 方案 A：只测逻辑支路（推荐，零改动）

```
电池 ──► TB6612 VM ──► 电机（不测）
                └──► 5V 输出 ──[INA226 IN+]──[R100mΩ]──[IN-]──► ESP32/屏/雷达/舵机
```

| 优点 | 缺点 |
|---|---|
| 无需改硬件 | 看不到电机电流 |
| 可测整机逻辑功耗（~0.7A，正好在量程内） | 电机堵转/过流检测不到 |

**本项目推荐此方案**：电机电流用 TB6612 的 ADC（VM 电压）+ 编码器堵转判定代替。

### 方案 B：改焊采样电阻（10 mΩ）

| 项目 | 改前 | 改后 |
|---|---|---|
| 阻值 | 100 mΩ | **10 mΩ**（1206/2512 合金电阻） |
| 量程 | 0.82 A | **8.19 A** |
| 3A 时压降 | 0.3 V | **0.03 V** |
| 3A 时功耗 | 0.9 W | **0.09 W** |
| 分辨率 | 0.1 mA | 1 mA |

**操作**：热风枪拆下 R3，换 10mΩ ±1% 合金电阻，代码改 `INA226_CAL_R_SHUNT = 0.01f`。

> 需要一定焊接能力，且改后无法再测小电流（μA 级）。

### 方案 C：只测总线电压（不改硬件）

把 IN+ 和 IN- 短接（或直接不串入回路），仅用 VBUS 引脚测电压。
INA226 的 VBUS 单独接电池正极即可，**不经过分流电阻**。

| 优点 | 缺点 |
|---|---|
| 安全，零风险 | 失去电流信息 |
| 电压精度 1.25mV | — |

> 适合只想做**电池电量显示**的场景。

## 4. 接口定义

### 4.1 模块 8P 排针

| Pin | 丝印 | 功能 | 说明 |
|---|---|---|---|
| 1 | **VCC** | 模块供电 | 2.7~5.5V，推荐 3.3V |
| 2 | **GND** | 地 | — |
| 3 | **SDA** | I2C 数据 | 需上拉（ESP32 内部可开） |
| 4 | **SCL** | I2C 时钟 | 需上拉 |
| 5 | **ALE** | 报警输出 | 开漏，可接 GPIO 做中断 |
| 6 | **VBS** | **总线电压输入** | 接被测电源正极（**不经分流电阻**） |
| 7 | **IN-** | 分流电阻负载侧 | 接负载正极 |
| 8 | **IN+** | 分流电阻电源侧 | 接电源正极 |

> ⚠️ **VBS 与 IN+ 的区别**：VBS 是纯电压测量脚（高阻），IN+ 是电流通路。若只测电压，只接 VBS。

### 4.2 板载跳线（地址设置）

| A1 | A0 | 7 位地址 | 8 位写 | 8 位读 |
|---|---|---|---|---|
| GND | GND | **0x40** | 0x80 | 0x81 |
| GND | VCC | 0x41 | 0x82 | 0x83 |
| VCC | GND | 0x44 | 0x88 | 0x89 |
| VCC | VCC | 0x45 | 0x8A | 0x8B |

> 模块默认两个焊点都接地 → **0x40**。本车只用一颗，保持默认。

## 5. 寄存器与校准

### 5.1 寄存器地图

| 地址 | 名称 | 读写 | 说明 |
|---|---|---|---|
| `0x00` | **CONFIG** | R/W | 平均次数、转换时间、模式 |
| `0x01` | SHUNT_V | R | 分流电压（1.25µV/LSB，有符号） |
| `0x02` | **BUS_V** | R | 总线电压（**1.25mV/LSB**） |
| `0x03` | POWER | R | 功率（25×Current LSB） |
| `0x04` | **CURRENT** | R | 电流（依赖校准） |
| `0x05` | **CALIBRATION** | R/W | 校准值（必须写） |
| `0x06` | MASK_EN | R/W | 报警使能 |
| `0x07` | ALERT_LIMIT | R/W | 报警阈值 |

### 5.2 CONFIG 寄存器（0x00）

| Bit | 字段 | 值 | 含义 |
|---|---|---|---|
| 15 | RST | 0/1 | 复位 |
| 13:11 | AVG | `010` | 4 次平均 |
| 10:8 | VBUS_CT | `100` | 总线转换 1.1ms |
| 7:5 | VSH_CT | `100` | 分流转换 1.1ms |
| 2:0 | MODE | `111` | 连续测分流+总线 |

**推荐值**：`0x4527`（4 次平均，1.1ms，连续模式）

### 5.3 校准值计算（**必做**）

```
Current_LSB = I_MAX / 32768
CAL         = 0.00512 / (Current_LSB × R_SHUNT)

以 R_SHUNT = 0.1Ω，I_MAX = 0.8A 为例：
  Current_LSB = 0.8 / 32768 = 24.4 µA
  CAL = 0.00512 / (24.4e-6 × 0.1) = 2098 ≈ 0x832
```

```c
static esp_err_t ina226_calibrate(float r_shunt, float i_max)
{
    float current_lsb = i_max / 32768.0f;
    uint16_t cal = (uint16_t)(0.00512f / (current_lsb * r_shunt));
    return ina226_write_reg16(0x05, cal);
}
```

### 5.4 数据换算

```c
float ina226_read_bus_voltage(void)   { return read_reg16(0x02) * 0.00125f; }        /* V */
float ina226_read_shunt_voltage(void) { return (int16_t)read_reg16(0x01) * 1.25e-6f; } /* V */
float ina226_read_current(void)       { return (int16_t)read_reg16(0x04) * CURRENT_LSB; } /* A */
float ina226_read_power(void)         { return read_reg16(0x03) * 25 * CURRENT_LSB; }  /* W */
```

## 6. 软件抽象设计（`pwr` 模块）

### 6.1 模块职责与边界

**负责**：INA226 初始化、周期采样、滤波、电量估算、低压告警、上报 `0x12` 帧。
**不负责**：电机过流判定（由 `mtr` 模块做）。

### 6.2 常量与配置宏

```c
/* pwr_cfg.h */
#define PWR_I2C_ADDR            0x40
#define PWR_I2C_FREQ_HZ         400000

/* ⚠️ 必须与板上实际电阻一致！默认 0.1Ω */
#define PWR_R_SHUNT             0.1f
#define PWR_I_MAX               0.8f
#define PWR_CURRENT_LSB         (PWR_I_MAX / 32768.0f)

#define PWR_SAMPLE_MS           500         /* 2Hz 采样 */
#define PWR_AVG_WINDOW          8           /* 滑动平均点数 */

/* 电池参数（2S 18650） */
#define PWR_BAT_CELLS           2
#define PWR_BAT_FULL_MV         8400        /* 4.2V × 2 */
#define PWR_BAT_EMPTY_MV        6400        /* 3.2V × 2 */
#define PWR_BAT_WARN_MV         7000        /* 3.5V × 2 告警 */
#define PWR_BAT_CUTOFF_MV       6600        /* 3.3V × 2 禁止电机 */

/* 电池容量（待实测） */
#define PWR_BAT_CAPACITY_MAH    2000

#define PWR_ALERT_GPIO          -1          /* ALE 接 GPIO，-1 表示不用 */
```

### 6.3 数据结构

```c
typedef struct {
    float    bus_v;         /* 总线电压 V */
```

### 6.8 关键实现

```c
/* Arduino Wire 实现（与 MPU6050 共用同一条 I2C 总线） */
static bool ina226_read_reg16(uint8_t reg, uint16_t *out)
{
    Wire.beginTransmission(PWR_I2C_ADDR);
    Wire.write(reg);
    if (Wire.endTransmission(false) != 0) return false;
    if (Wire.requestFrom((uint8_t)PWR_I2C_ADDR, (uint8_t)2) != 2) return false;
    uint8_t hi = Wire.read(), lo = Wire.read();
    *out = (hi << 8) | lo;
    return true;
}

static bool ina226_write_reg16(uint8_t reg, uint16_t val)
{
    Wire.beginTransmission(PWR_I2C_ADDR);
    Wire.write(reg);
    Wire.write(val >> 8);
    Wire.write(val & 0xFF);
    return Wire.endTransmission() == 0;
}

esp_err_t pwr_init(void)
{
    /* 1. 配置：4 次平均，1.1ms，连续模式 */
    if (!ina226_write_reg16(0x00, 0x4527)) {
        ESP_LOGE(TAG, "config write failed");
        return ESP_ERR_TIMEOUT;
    }

    /* 2. 校准（关键！） */
    float current_lsb = PWR_I_MAX / 32768.0f;
    uint16_t cal = (uint16_t)(0.00512f / (current_lsb * PWR_R_SHUNT));
    if (!ina226_write_reg16(0x05, cal)) {
        ESP_LOGE(TAG, "calibration write failed");
        return ESP_ERR_TIMEOUT;
    }
    ESP_LOGI(TAG, "calibrated: R=%.4fΩ Imax=%.2fA CAL=0x%04X", PWR_R_SHUNT, PWR_I_MAX, cal);

    /* 3. 自检：配置回读 */
    uint16_t cfg = 0;
    if (!ina226_read_reg16(0x00, &cfg) || cfg != 0x4527) {
        ESP_LOGW(TAG, "config readback 0x%04X", cfg);
    }
    return ESP_OK;
}
```

## 7. 电量估算

18650 锂电池的电压-SOC 曲线是非线性的，且**放电中段很平**（3.6~3.9V 占 60% 容量），单靠电压估算误差大。

### 7.1 简化查表（够用）

| 电压（单体） | SOC |
|---|---|
| 4.20 V | 100% |
| 4.10 V | 90% |
| 4.00 V | 80% |
| 3.90 V | 65% |
| 3.80 V | 50% |
| 3.70 V | 35% |
| 3.60 V | 20% |
| 3.50 V | 10% |
| 3.30 V | 0% |

```c
uint8_t pwr_estimate_soc(float v_bat)
{
    static const struct { float v; uint8_t s; } tbl[] = {
        {4.20f, 100}, {4.10f, 90}, {4.00f, 80}, {3.90f, 65},
        {3.80f, 50},  {3.70f, 35}, {3.60f, 20}, {3.50f, 10}, {3.30f, 0},
    };
    float v_cell = v_bat / PWR_BAT_CELLS;
    if (v_cell >= tbl[0].v) return 100;
    for (int i = 1; i < 9; i++) {
        if (v_cell >= tbl[i].v) {
            float k = (v_cell - tbl[i].v) / (tbl[i-1].v - tbl[i].v);
            return tbl[i].s + k * (tbl[i-1].s - tbl[i].s);
        }
    }
    return 0;
}
```

### 7.2 更准的方法（可选）

**库仑计**：`SOC = SOC0 - ∫I dt / Capacity`
需要 INA226 持续积分。缺点：电流测量有零漂，长期积分会累积误差。

> 本项目用**电压查表 + 负载补偿**（加载时电压会跌落 0.2~0.4V，估算时加回）即可。

## 8. 错误处理与自检

| 检查 | 方法 | 处理 |
|---|---|---|
| 器件在线 | 读 CONFIG 回读 == 写入值 | 失败 → 上报离线 |
| I2C 通信 | 连续 5 次 NAK | 重初始化总线 |
| 电压异常 | >9V 或 <5V | 置故障，可能是接线错误 |
| 电流饱和 | \|I\| > 0.78A | 标记"超量程"，提示改硬件 |
| 电压抖动 | 单次跳变 >0.5V | 丢弃该点（滤波） |

## 9. 与上位机的契约

**上行帧 `0x12`（电源）**

| 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|
| `vbus_mv` | uint16 | mV | 总线电压 |
| `current_ma` | int16 | mA | 电流（正=放电） |
| `power_mw` | uint16 | mW | 功率 |
| `soc` | uint8 | % | 电量 |
| `flags` | uint8 | — | bit0=低压 bit1=超量程 bit2=离线 |

帧长 = 2+2+2+1+1 = 8 字节，频率 **2Hz**。

## 11. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 电流读数全是 0.8A | 超量程饱和 | 改硬件（方案 B）或缩小测量范围 |
| 电流读数偏大/偏小 10 倍 | `R_SHUNT` 宏与实际不符 | 万用表量 R3，改宏 |
| 电压读数不准 | VBS 未接或接错 | VBS 接被测正极 |
| I2C 扫描不到 | 地址错 / 供电不足 | 试 0x40/0x41/0x44/0x45 |
| 数值跳变 | 未平均 | 设 AVG=4 或软件滑动平均 |
| 模块发烫 | 分流电阻功耗大 | 减小电流或换 10mΩ |
