### 3.1 4PIN 接口（1.5mm 间距）

| Pin | 信号 | 说明 |
|---|---|---|
| 1 | **TXD** | 雷达发送 → ESP32 RX |
| 2 | **RXD** | 雷达接收 ← ESP32 TX |
| 3 | **GND** | 地 |

### 3.2 坐标系定义

- 遵循**左手法则**（雷达自身定义），原点为测距核心旋转中心。
- 角度**随顺时针方向增大**。
- 零度角方向：雷达出光窗口正对方向（见规格书图 3）。

> ⚠️ **与 ROS 右手系相反**。ROS 中角度逆时针增大。ROS2 驱动的 `reversion: true` 参数就是做这个翻转。
> **本车安装朝向需在 URDF 里用 `laser_link` 的 rpy 补偿**，不要改数据。

## 4. 通信协议（核心）

### 4.1 控制指令

| 功能 | 发送（4 字节） | 成功应答 |
|---|---|---|
| **启动扫描** | `AA 55 F0 0F` | `A5 5A 50 07 00 00 00 00 00 00 00 A8` |
| **停止扫描** | `AA 55 F5 0A` | `A5 5A 55 07 00 00 00 00 00 00 00 AD` |
| 失败应答 | — | `A5 5A 55 07 ... E9` |
| 低曝光（预留） | `AA 55 F1 0E` | — |
| 高曝光（预留） | `AA 55 F2 0D` | — |
| 读版本（预留） | `AA 55 FC 03` | — |

> **上电后雷达处于停止状态**，必须发启动指令才开始出数据。

### 4.2 数据包通用格式

```
A5 5A | LEN_L LEN_H | CS_L CS_H | TYPE | DATA...
```

| 字段 | 长度 | 说明 |
|---|---|---|
| 包头 | 2B | 固定 `A5 5A` |
| 长度 | 2B | 小端，**指 DATA 区长度** |
| 校验和 | 2B | 小端，除本字段外所有字节累加和 |
| 类型 | 1B | `0x81` = 点云数据；`0x01` = 设备信息 |
| 数据区 | nB | 见下 |

### 4.3 设备信息包（上电第一条，TYPE=0x01）

```
A5 5A 14 00 E3 02 01 <20 字节数据区>
```

| 偏移 | 内容 |
|---|---|
| 1~7 | 型号 ASCII `"COIN-D6"` |
| 8~12 | 保留 |
| 13~14 | 零度角偏差（结构已补偿，忽略） |
| 15 | 旋转方向：`0x00` = 顺时针 |
| 16 | `0x01` = 需在驱动中做角度矫正 |
| 17~19 | 保留 |
| 20 | 软件版本 `0x01` = Rev1 |

### 4.4 点云数据包（TYPE=0x81）

**包内结构**

```
PHL PHH | M&T | LSN | FSA_L FSA_H | LSA_L LSA_H | CS_L CS_H | S1(3B) S2(3B) ... Sn(3B) | AA 55
```

| 字段 | 长度 | 说明 |
|---|---|---|
| **PH** | 2B | 包头，固定 `0x55AA`（小端 → 字节序 `AA 55`） |
| **M&T** | 1B | bit7~1 = 扫描频率 M；bit0 = 包类型 T |
| **LSN** | 1B | 本包采样点数量 |
| **FSA** | 2B | 起始角，小端 |
| **LSA** | 2B | 结束角，小端 |
| **CS** | 2B | 双字节异或校验（本字段不参与） |
| **Si** | 3B × N | 采样点（距离+强度+高反标志） |
| 尾 | 2B | `AA 55` |

**M&T 解析**
```
T = M&T & 0x01          0=点云包，1=起始包（一圈的第一个包，LSN=1）
M = (M&T >> 1)          扫描频率（仅起始包有效）
```

**Si 解析（3 字节：Si_L, Si_2nd, Si_H）**
```
距离(mm)     = Si_H * 64 + (Si_2nd >> 2)               // 14 bit
强度(0~255)  = (Si_2nd & 0x03) * 64 + (Si_L >> 2)      // 8 bit
高反标志     = Si_2nd & 0x01                            // 1=高反材质
```

**角度解析（小端，C 位固定为 1）**
```
Angle_fsa = (FSA >> 1) / 64.0
Angle_lsa = (LSA >> 1) / 64.0
Angle(i)  = Angle_fsa + (Angle_lsa - Angle_fsa) / (LSN - 1) * (i - 1)     // i=2..LSN
```

**校验（CS）**
```
按字节异或，顺序：PHL,PHH,M&T,LSN,FSA_L,FSA_H,LSA_L,LSA_H,
                  S1_L,S1_2nd,S1_H(补零到8位),S2_L,...
结果低 16 位即 CS（小端存放）
```

### 4.5 完整解析示例

```
A5 5A 1A 00 xx xx 81
AA 55 01 08 00 00 20 03 3C 01                    <- 包头 M&T LSN FSA=0x0000 LSA=0x0320 CS=0x013C
[3B][3B][3B][3B][3B][3B][3B][3B]                 <- 8 个采样点
AA 55
```

- `LSN=8` → 8 个点
- `FSA=0x0000` → 起始角 `(0>>1)/64 = 0°`
- `LSA=0x0320=800` → 结束角 `(800>>1)/64 = 6.25°`
- 角度步进 = `6.25 / 7 ≈ 0.893°` ≈ 0.9° ✅

## 5. 两种接入方式

### 5.1 方式 A：USB 直连上位机（**调试/建图首选**）

雷达资料包自带 USB 转串口线（CH340，`1a86:7523`），直接插笔记本：

```
D6 ──USB──► 笔记本 ──► ROS2 节点 m1ct_d2 ──► /scan
```

**优点**：零开发量，直接用官方包；带宽无瓶颈；ESP32 减负。
**缺点**：需要一根 USB 线从车到笔记本（本车 WiFi 通信，笔记本不随车 → **不可行**）。

### 5.2 方式 B：UART 接 ESP32 + WiFi 转发（**本车实际方案**）

```
D6 ──UART 230400──► ESP32-S3 ──WiFi UDP──► 笔记本 ──► ROS2 桥接节点 ──► /scan
```

**带宽核算**

| 项目 | 计算 | 结果 |
|---|---|---|
| 点频 | 4000 点/s | — |
| 单点原始字节 | 3 B | — |
| 原始数据率 | 4000 × 3 | **12 KB/s** |
| 加包头开销（~10%） | 12 × 1.1 | **≈13.2 KB/s** |
| UDP over WiFi | 13.2 × 8 | **≈106 kbps** |

> 结论：**WiFi 完全够用**，即使 2.4GHz 拥堵也仅占约 5% 带宽。

**延迟核算**

| 环节 | 延迟 |
|---|---|
| 串口接收（DMA 双缓冲） | <1 ms |
| 解析 + 组包 | <1 ms |
| WiFi 发送（UDP） | 2~10 ms |
| **单包端到端** | **<15 ms** |

> 一圈 100ms（10Hz），15ms 延迟可接受。**SLAM 建图不受影响**（slam_toolbox 对 100ms 级延迟不敏感）。

### 6.8 解析核心实现

```c
static void lidar_parse_byte(uint8_t b)
{
    switch (s_ps) {
    case LID_ST_WAIT_H0:
        if (b == LID_HEADER_0) s_ps = LID_ST_WAIT_H1;
        break;
    case LID_ST_WAIT_H1:
        s_ps = (b == LID_HEADER_1) ? LID_ST_LEN_L : LID_ST_WAIT_H0;
        break;
    case LID_ST_LEN_L:
        s_pkt_len = b;  s_ps = LID_ST_LEN_H;
        break;
    case LID_ST_LEN_H:
        s_pkt_len |= (b << 8);
        if (s_pkt_len > sizeof(s_data_buf)) { s_ps = LID_ST_WAIT_H0; g_lidar.pkt_err++; break; }
        s_ps = LID_ST_CS_L;
        break;
    case LID_ST_CS_L:
        s_pkt_cs = b;  s_ps = LID_ST_CS_H;
        break;
    case LID_ST_CS_H:
        s_pkt_cs |= (b << 8);
        s_ps = LID_ST_TYPE;
        break;
    case LID_ST_TYPE:
        s_pkt_type = b;
        s_data_idx = 0;
        s_ps = (s_pkt_len > 0) ? LID_ST_DATA : LID_ST_WAIT_H0;
        if (s_pkt_len == 0) lidar_handle_packet(s_pkt_type, NULL, 0);
        break;
    case LID_ST_DATA:
        s_data_buf[s_data_idx++] = b;
        if (s_data_idx >= s_pkt_len) {
            lidar_handle_packet(s_pkt_type, s_data_buf, s_pkt_len);
            s_ps = LID_ST_WAIT_H0;
        }
        break;
    }
}
```

**点云包处理**

```c
static void lidar_handle_cloud(const uint8_t *d, uint16_t len)
{
    if (len < 10) return;

    /* 校验：除 CS 外所有字节异或 */
    uint16_t cs = 0;
    for (int i = 0; i < 8; i++) cs ^= d[i];       /* PH..LSA */
    int n = d[3];                                  /* LSN */
    for (int i = 0; i < n; i++) {
        cs ^= d[10 + i*3 + 0];
        cs ^= d[10 + i*3 + 1];
        cs ^= d[10 + i*3 + 2];
    }
    uint16_t pkt_cs = d[8] | (d[9] << 8);
    if (cs != pkt_cs) { g_lidar.pkt_err++; return; }

    uint8_t  m_t   = d[2];
    uint8_t  is_start = m_t & 0x01;
    uint16_t fsa   = d[4] | (d[5] << 8);
    uint16_t lsa   = d[6] | (d[7] << 8);
    float f_deg = (fsa >> 1) / 64.0f;
    float l_deg = (lsa >> 1) / 64.0f;

    if (is_start) {
        /* 一圈开始：交换缓冲，通知发送任务 */
        lidar_finish_scan();
    }

    for (int i = 0; i < n; i++) {
        const uint8_t *s = &d[10 + i*3];
        uint16_t dist  = (s[2] * 64) + (s[1] >> 2);
        uint8_t  inten = ((s[1] & 0x03) * 64) + (s[0] >> 2);
        float ang = (n > 1) ? (f_deg + (l_deg - f_deg) / (n - 1) * i) : f_deg;

        lid_scan_t *sc = &s_scan_buf[s_scan_wr_idx];
        if (sc->count >= LID_POINTS_PER_SCAN) break;
        sc->pts[sc->count].angle_cdeg = (uint16_t)(ang * 100.0f) % 36000;
        sc->pts[sc->count].dist_mm    = (dist >= LID_RANGE_MIN_MM && dist <= LID_RANGE_MAX_MM)
                                        ? dist : 0;
        sc->count++;
        (void)inten;   /* 强度暂不使用，可扩展 */
    }
    g_lidar.pkt_ok++;
}
```

### 6.9 上行帧打包（UDP）

```c
/* 0x20 帧：一圈点云分片发送
   DATA = [seq(1B)][total(2B)][idx(2B)][count(1B)][angle,dist × count] */
esp_err_t lidar_send_scan_udp(const lid_scan_t *sc)
{
    uint16_t total = (sc->count + LID_MAX_POINTS_PER_PKT - 1) / LID_MAX_POINTS_PER_PKT;
    uint8_t  buf[LID_UDP_MTU_SAFE];
    uint16_t off = 0;

    for (uint16_t p = 0; p < total; p++) {
        uint16_t cnt = sc->count - p * LID_MAX_POINTS_PER_PKT;
        if (cnt > LID_MAX_POINTS_PER_PKT) cnt = LID_MAX_POINTS_PER_PKT;

        /* 组 X-Protocol 帧头 */
        uint8_t *q = buf;
        *q++ = 0xAA; *q++ = 0x55;
        uint8_t len_pos = (uint8_t)(q - buf); q++;
        *q++ = LID_FRAME_ID;
        uint8_t *data_start = q;
        *q++ = sc->seq;
        *q++ = total >> 8;   *q++ = total & 0xFF;
        *q++ = p >> 8;       *q++ = p & 0xFF;
        *q++ = (uint8_t)cnt;
        for (uint16_t i = 0; i < cnt; i++) {
            const lid_point_t *pt = &sc->pts[p * LID_MAX_POINTS_PER_PKT + i];
            *q++ = pt->angle_cdeg >> 8;  *q++ = pt->angle_cdeg & 0xFF;
            *q++ = pt->dist_mm >> 8;     *q++ = pt->dist_mm & 0xFF;
        }
        uint8_t frame_len = (uint8_t)(q - buf) + 1;
        buf[len_pos] = frame_len;
        uint8_t cs = 0;
        for (uint8_t *r = buf; r < q; r++) cs += *r;
        *q++ = cs;

        sendto(s_udp_sock, buf, q - buf, 0, (struct sockaddr *)&g_host_addr, sizeof(g_host_addr));
        off += cnt;
    }
    return ESP_OK;
}
```

> **分片原因**：一圈 400 点 × 4B = 1600B，超过安全 MTU（1200B）。分成每包 60 点（240B + 头 13B），约 7 个 UDP 包/圈，70 包/秒。

### 6.10 任务

| 任务 | 核心 | 优先级 | 栈 | 触发 | 职责 |
|---|---|---|---|---|---|
| `task_lid_parse` | 1 | 9 | 4096 | UART 事件 | 字节流解析 → 点云 |
| `task_lid_tx` | 0 | 7 | 4096 | 信号量（一圈完成） | 打包 → UDP 发送 |

## 7. 错误处理与自检

| 检查 | 方法 | 处理 |
|---|---|---|
| 无数据 | 启动后 2s 内无任何字节 | 重发启动指令 ×3，仍无 → 上报离线 |
| 校验失败率高 | `pkt_err / (ok+err) > 10%` | 检查波特率、地线、电源纹波 |
| 转速异常 | 起始包间隔 >150ms 或 <80ms | 上报转速异常 |
| 数据中断 | `now - last_rx_ms > 500` | 上报离线，尝试重启雷达 |
| 点云异常 | 单圈有效点 < 50 | 标记该圈无效，不发送 |

### 7.1 启动时序

```
上电 → 等待 500ms（雷达自检）→ 发 LID_CMD_START → 等 ACK（A5 5A 50 07…）
     → 等设备信息包（TYPE=0x01，解析到 "COIN-D6"）
     → 等第一个起始包（M&T bit0=1）
     → 进入正常输出
```

## 8. 与上位机的契约

### 8.1 传输层

| 项 | 值 |
|---|---|
| 协议 | UDP |
| 端口 | **8889** |
| 目的地址 | 笔记本 WiFi IP |
| 帧格式 | X-Protocol（`AA 55 LEN ID DATA CS`） |
| 帧 ID | **0x20** |

### 8.2 数据布局

```
DATA:
  [0]     seq        圈序号 0~255
  [1..2]  total      本圈分片总数（大端）
  [3..4]  idx        当前分片序号（大端，从 0 开始）
  [5]     count      本片点数
  [6..]   points     count × 4 字节
           每点：angle_cdeg(2B 大端，0~35999) + dist_mm(2B 大端，0=无效)
```

### 8.3 上位机 ROS2 桥接节点

```python
#!/usr/bin/env python3
"""lidar_bridge: UDP(0x20) -> sensor_msgs/LaserScan"""
import socket, struct, rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan

FRAME_ID = "laser_link"
ANGLE_MIN, ANGLE_MAX = -3.14159, 3.14159
RANGE_MIN, RANGE_MAX = 0.05, 12.0

class LidarBridge(Node):
    def __init__(self):
        super().__init__('lidar_bridge')
        self.pub = self.create_publisher(LaserScan, '/scan', 10)
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        self.sock.bind(('0.0.0.0', 8889))
        self.sock.settimeout(1.0)
        self.buf = {}          # seq -> {idx: pts}
        self.create_timer(0.001, self.poll)

    def poll(self):
        try:
            data, _ = self.sock.recvfrom(2048)
        except socket.timeout:
            return
        # 解析 X-Protocol
        if len(data) < 6 or data[0] != 0xAA or data[1] != 0x55:
            return
        flen, fid = data[2], data[3]
        if fid != 0x20:
            return
        cs = sum(data[:flen-1]) & 0xFF
        if cs != data[flen-1]:
            return
        d = data[4:flen-1]
        seq = d[0]
        total = (d[1] << 8) | d[2]
        idx = (d[3] << 8) | d[4]
        cnt = d[5]
        pts = []
        for i in range(cnt):
            a = (d[6+i*4] << 8) | d[7+i*4]
            r = (d[8+i*4] << 8) | d[9+i*4]
            pts.append((a / 100.0, r / 1000.0))
        self.buf.setdefault(seq, {})[idx] = pts
        if len(self.buf[seq]) == total:
            self.publish_scan(self.buf.pop(seq), total)

    def publish_scan(self, parts, total):
        ranges = [float('inf')] * 400
        for i in range(total):
            for ang_deg, r in parts[i]:
                # 雷达顺时针 -> ROS 逆时针
                idx = int(((360.0 - ang_deg) % 360.0) / 0.9) % 400
                ranges[idx] = r if r > 0 else float('inf')
        msg = LaserScan()
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.header.frame_id = FRAME_ID
        msg.angle_min = ANGLE_MIN
        msg.angle_max = ANGLE_MAX
        msg.angle_increment = 2 * 3.14159 / 400
        msg.range_min = RANGE_MIN
        msg.range_max = RANGE_MAX
        msg.ranges = ranges
        self.pub.publish(msg)

def main():
    rclpy.init()
    rclpy.spin(LidarBridge())
    rclpy.shutdown()
```

> **角度翻转**：`(360 - ang) % 360` 把雷达顺时针坐标系转成 ROS 逆时针。若整车安装有额外旋转，改 URDF 的 `laser_link`。

## 9. 与官方 ROS2 包的对照

| 项 | 官方 `m1ct_d2` | 本项目 |
|---|---|---|
| 接入 | USB `/dev/sc_mini` | UART → WiFi |
| 参数 | `version: 4`（M1CT_Coin_D2） | 同 |
| `frame_id` | `laser_link` | 同 |
| `baudrate` | 230400 | 同 |
| `angle_min/max` | -180 / 180 | 同 |
| `range_min/max` | 0.01 / 16.0 | **0.05 / 12.0**（按实际规格） |
| `frequency` | 10.0 | 同 |
| `reversion` | true（角度翻转） | 桥接节点里做 |

> 官方包 `params/m1ct_d2.yaml` 的 `max_range: 16.0` 是驱动上限，不是雷达能力。**实际按 12m 配置**，避免把噪点当有效点。
