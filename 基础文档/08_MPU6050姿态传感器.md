# 设备说明：MPU6050 六轴姿态传感器

> 项目：ESP32-S3 两轮差速 ROS2 智能小车
> 文档版本：**v1.0**　｜　正式发布版
> 生成日期：2026-11-07
> 资料目录：`8-MPU6050模块镀金板焊直针/`

---

## 1. 设备概述

| 项目 | 内容 |
|---|---|
| 型号 | **MPU6050**（InvenSense，现 TDK） |
| 类型 | 六轴运动处理单元（3 轴陀螺 + 3 轴加速度） |
| 内置 | 温度传感器 + **DMP（数字运动处理器）** |
| 接口 | **I2C（最高 400kHz）** + 辅助 I2C（接磁力计） |
| 模块供电 | **3.3V 或 5V**（板载 LDO） |
| I2C 地址 | **0x68**（AD0=GND，默认）/ 0x69（AD0=VDD） |
| 上拉 | 板载 **4.7kΩ**（SDA/SCL），外部无需再加 |

> **DMP 是关键**：硬件直接输出四元数/欧拉角，免去在 ESP32 上跑复杂的姿态融合算法。

## 3. 寄存器地图（常用）

| 地址 | 名称 | 说明 |
|---|---|---|
| `0x6B` | **PWR_MGMT_1** | 电源管理，`0x00`=唤醒，`0x01`=PLL 陀螺 X 参考 |
| `0x6C` | PWR_MGMT_2 | 各轴待机控制 |
| `0x1A` | CONFIG | DLPF 配置（`0x03`=44Hz） |
| `0x1B` | GYRO_CONFIG | 陀螺量程（`0x00`=±250，`0x18`=±2000） |
| `0x1C` | ACCEL_CONFIG | 加速度量程（`0x00`=±2g，`0x18`=±16g） |
| `0x19` | **SMPLRT_DIV** | 采样率分频（1kHz/(1+div)） |
| `0x3B~0x40` | ACCEL_XOUT_H..ZOUT_L | 加速度原始值（6B，大端） |
| `0x41~0x42` | TEMP_OUT_H/L | 温度 |
| `0x43~0x48` | GYRO_XOUT_H..ZOUT_L | 陀螺原始值（6B，大端） |
| `0x3A` | INT_ENABLE | 中断使能（`0x01`=数据就绪） |
| `0x75` | **WHO_AM_I** | 固定返回 `0x68`（自检用） |

### 3.1 初始化序列（标准）

```
1. PWR_MGMT_1 = 0x80        // 复位
2. delay 100ms
3. PWR_MGMT_1 = 0x01        // 唤醒，PLL X 轴陀螺参考
4. SMPLRT_DIV = 0x09        // 100Hz 采样（1kHz/10）
5. CONFIG     = 0x03        // DLPF 44Hz
6. GYRO_CONFIG  = 0x18      // ±2000°/s
7. ACCEL_CONFIG = 0x10      // ±8g
8. INT_ENABLE = 0x01        // 数据就绪中断
```

### 3.2 数据换算

```
加速度(g)   = raw / 灵敏度        // ±8g 时 4096 LSB/g
陀螺(°/s)   = raw / 灵敏度        // ±2000 时 16.4 LSB/(°/s)
温度(℃)     = raw / 340.0 + 36.53
```

## 4. 姿态解算方案对比

| 方案 | 实现 | 精度 | CPU 占用 | 推荐度 |
|---|---|---|---|---|
| **A. DMP 硬件解算** | 加载 `dmpKey.h` 固件，读 FIFO | ±1° | 极低 | **✅ 推荐** |
| B. 互补滤波 | 陀螺积分 + 加速度校正 | ±2° | 低 | 备选 |
| C. Mahony/Madgwick | 四元数融合 | ±1° | 中 | 备选 |
| D. 卡尔曼 | 状态估计 | ±0.5° | 高 | 不必要 |

**DMP 优点**：ESP32 只读结果，零算法负担；输出四元数，可直接转 ROS `imu` 消息。
**DMP 缺点**：依赖 InvenSense 闭源固件（`dmpKey.h` ~3KB），移植稍麻烦。

> **本项目建议 A（DMP）**，若移植受阻则退化为 B（互补滤波，20 行代码即可）。

## 5. 软件抽象设计（`imu` 模块）

### 5.1 模块职责与边界

**负责**：I2C 通信、寄存器配置、原始数据读取、姿态解算、零偏校准、发布 `imu` 帧。
**不负责**：航向融合（与里程计融合由上位机 `robot_localization` 做）。

### 5.2 常量与配置宏

```c
/* imu_cfg.h */
#define IMU_I2C_ADDR            0x68
#define IMU_I2C_FREQ_HZ         400000
#define IMU_WHO_AM_I_VAL        0x68

#define IMU_SAMPLE_HZ           100
#define IMU_SMPLRT_DIV          (1000 / IMU_SAMPLE_HZ - 1)   /* 9 */
#define IMU_DLPF_CFG            0x03                          /* 44Hz */

#define IMU_GYRO_FS_SEL         0x18        /* ±2000 °/s */
#define IMU_GYRO_LSB_PER_DPS    16.4f
#define IMU_ACCEL_FS_SEL        0x10        /* ±8 g */
#define IMU_ACCEL_LSB_PER_G     4096.0f

#define IMU_USE_DMP             1
#define IMU_CALIB_SAMPLES       500         /* 零偏校准采样数 */
#define IMU_CALIB_MS            3000

/* 安装方向补偿（芯片坐标 → 车身坐标） */
#define IMU_AXIS_SWAP_XY        0
#define IMU_AXIS_INVERT_X       0
#define IMU_AXIS_INVERT_Y       0
#define IMU_AXIS_INVERT_Z       0
```

### 5.3 数据结构

```c
/* 原始数据 */
typedef struct {
    int16_t accel[3];       /* LSB */
    int16_t gyro[3];        /* LSB */
    int16_t temp;           /* LSB */
    uint32_t stamp_ms;
} imu_raw_t;

/* 物理量 */
typedef struct {
    float accel_mps2[3];    /* m/s² */
    float gyro_radps[3];    /* rad/s */
    float temp_c;
    uint32_t stamp_ms;
} imu_scaled_t;

/* 姿态（欧拉角，度） */
typedef struct {
    float roll;             /* 横滚 */
    float pitch;            /* 俯仰 */
    float yaw;              /* 航向（无磁力计时会漂移） */
    float q[4];             /* 四元数 w,x,y,z */
    uint32_t stamp_ms;
} imu_att_t;

/* 零偏 */
typedef struct {
    float gx, gy, gz;       /* 陀螺零偏 原始 LSB */
    float ax, ay, az;       /* 加速度零偏 */
    bool  valid;
} imu_bias_t;
```

### 5.8 关键实现

```c
/* Arduino Wire 实现（与 INA226 共用同一条 I2C 总线） */
static bool imu_write_reg(uint8_t reg, uint8_t val)
{
    Wire.beginTransmission(IMU_I2C_ADDR);
    Wire.write(reg);
    Wire.write(val);
    return Wire.endTransmission() == 0;
}

static bool imu_read_regs(uint8_t reg, uint8_t *buf, size_t len)
{
    Wire.beginTransmission(IMU_I2C_ADDR);
    Wire.write(reg);
    if (Wire.endTransmission(false) != 0) return false;              /* repeated start */
    if (Wire.requestFrom((uint8_t)IMU_I2C_ADDR, (uint8_t)len) != len) return false;
    for (size_t i = 0; i < len; i++) buf[i] = Wire.read();
    return true;
}

esp_err_t imu_init(void)
{
    /* 1. 自检 */
    uint8_t who = 0;
    if (!imu_read_regs(0x75, &who, 1)) {
        ESP_LOGE(TAG, "I2C read failed");
        return ESP_ERR_TIMEOUT;
    }
    if (who != IMU_WHO_AM_I_VAL) {
        ESP_LOGE(TAG, "WHO_AM_I=0x%02X, expect 0x68", who);
        return ESP_ERR_NOT_FOUND;
    }

    /* 2. 复位 + 唤醒 */
    imu_write_reg(0x6B, 0x80);
    vTaskDelay(pdMS_TO_TICKS(100));
    imu_write_reg(0x6B, 0x01);

    /* 3. 配置 */
    imu_write_reg(0x19, IMU_SMPLRT_DIV);
    imu_write_reg(0x1A, IMU_DLPF_CFG);
    imu_write_reg(0x1B, IMU_GYRO_FS_SEL);
    imu_write_reg(0x1C, IMU_ACCEL_FS_SEL);
    imu_write_reg(0x3A, 0x01);          /* 数据就绪中断 */

    ESP_LOGI(TAG, "MPU6050 init ok (0x%02X)", who);
    return ESP_OK;
}

/* 航迹推算：只用陀螺 Z 轴积分（短期准，长期漂） */
static void imu_update_yaw(float gz_radps, float dt)
{
    s_yaw_acc += gz_radps * dt;
    /* 归一化到 -π ~ π */
    while (s_yaw_acc >  M_PI) s_yaw_acc -= 2 * M_PI;
    while (s_yaw_acc < -M_PI) s_yaw_acc += 2 * M_PI;
    g_imu_att.yaw = s_yaw_acc * 180.0f / M_PI;
}
```

### 5.9 任务

| 任务 | 核心 | 优先级 | 栈 | 周期 | 职责 |
|---|---|---|---|---|---|
| `task_imu` | 1 | 11 | 4096 | 10 ms | 读数据 → 换算 → 姿态 → 更新全局 |

> 优先级高于电机控制（12）以下、低于通信？实际：**IMU 采样 11，电机 12**，电机优先保证实时性。

## 6. 安装与标定

### 6.1 安装要求

| 要求 | 说明 |
|---|---|
| 位置 | 靠近车体几何中心，**越低越好**（减小振动） |
| 朝向 | **芯片 X 轴指向车头**，Z 轴朝上（见模块丝印 X/Y） |
| 固定 | 双面胶 + 螺丝，**必须刚性连接**，不能悬空 |
| 减震 | 建议加 **硅胶减震柱**，否则电机振动会让陀螺噪声爆表 |
| 远离 | 电机、电源线、WiFi 天线（磁场/电磁干扰） |

### 6.2 零偏校准流程

```
1. 车放水平桌面，静止不动
2. 调用 imu_calibrate()
3. 采集 500 组（约 3s），求均值作为零偏
4. 校验：陀螺零偏应 < ±5 °/s，否则提示"请勿触碰"
5. 写入 NVS，下次启动自动加载
```

### 6.3 航向角使用注意

- **无磁力计时 yaw 会缓慢漂移**（约 1~3°/分钟）。
- **不能单独用于定位**。正确用法：
  - 短期（<10s）：可用 IMU yaw 做转向闭环
  - 长期：用 **雷达 SLAM 的位姿** 或 **轮式里程计** 校正
- 上位机用 `robot_localization` 的 `ekf_node` 融合 `/odom` + `/imu`，输出 `/odometry/filtered`。

## 7. 错误处理与自检

| 检查 | 方法 | 处理 |
|---|---|---|
| 器件存在 | `WHO_AM_I == 0x68` | 失败 → 上报离线，禁用 IMU 相关功能 |
| I2C 通信 | 连续 10 次 NAK | 重新初始化总线 |
| 数据异常 | 加速度模长偏离 9.8±2 m/s² 持续 1s | 标记"剧烈运动"，暂停校准 |
| 零偏过大 | 校准后 \|bias\| > 5°/s | 提示重新校准 |
| 温度漂移 | 温度变化 >10℃ | 建议重新校准 |

## 8. 与上位机的契约

**上行帧 `0x11`（IMU）**

| 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|
| `ax, ay, az` | int16 | 0.01 m/s² | 加速度 |
| `gx, gy, gz` | int16 | 0.01 rad/s | 角速度 |
| `roll, pitch` | int16 | 0.01 ° | 姿态角 |
| `yaw` | int16 | 0.01 ° | 航向（-18000~18000） |
| `temp` | int16 | 0.01 ℃ | 温度 |

帧长 = 6×2 + 4×2 + 2 = 22 字节，频率 **50Hz**（100Hz 采样降频发送）。

**上位机 → `sensor_msgs/Imu`**

```python
msg.orientation.x = q[1]; msg.orientation.y = q[2]
msg.orientation.z = q[3]; msg.orientation.w = q[0]
msg.linear_acceleration.x = ax
msg.angular_velocity.z = gz
msg.header.frame_id = "imu_link"
```

## 10. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| I2C 扫描不到 | AD0 接错 / 供电不足 | 试 0x68 和 0x69；测 VCC |
| 数据全 0 | 未唤醒（还在 sleep） | 写 `PWR_MGMT_1=0x00` |
| 数值剧烈跳动 | 电机振动 / 电源噪声 | 加减震、加 0.1µF、远离电机 |
| yaw 一直漂 | 正常现象（无磁力计） | 用里程计/SLAM 校正 |
| 姿态角发散 | 陀螺零偏未校准 | 跑 `imu_calibrate()` |
| 读数据偶尔失败 | I2C 总线被占 / 上拉不足 | 降速到 100kHz，检查上拉 |
