## 1. 这个文件夹是什么

塔克创新 R20 系列机器人（ROS 版）的**完整教程 + 固件 + APP 源码**资料包。

**性质**：**方法论参考**，不是本车器件资料。

| 项目 | 是否可直接用 |
|---|---|
| 器件参数 | ❌ R20 用的是 STM32F407 + MC520 电机，与本车不同 |
| ROS2 教程 | ✅ **流程与方法可直接学** |
| SLAM/Nav2 教程 | ✅ **上位机配置可直接照做** |
| 语音教程 | ⚠️ 用的是讯飞 R818 模块，与本车 LMD2718 方案不同 |
| STM32 固件 | ⚠️ 只能看协议与结构，不能直接烧 |
| ROS 源码 | ❌ **本地没有**（说明文件指向"镜像资料包"） |
| 手机 APP 源码 | ❌ 本车不用 |

## 4. 关键缺失：ROS 源码不在本地

`3 l 源码资料/ROS程序源码/ROS源码位置说明.txt` 内容（转码后）：

> 塔克创新 ROS 源码说明
> ROS 源码位于镜像资料包中，代码会不断更新完善…

**结论**：**上位机 ROS2 代码必须自己写**（或用文件夹 3 的 `m1ct_d2` + 本文档的桥接节点）。

好消息：本项目的协议（X-Protocol）和运动学（文件夹 2 源码）已经足够，ROS2 侧只需要：
- 一个 UDP 桥接节点（收发帧）
- 一个 URDF（车体模型）
- 标准包（slam_toolbox、Nav2）

## 7. 对本项目的三条具体建议

### 7.1 URDF 可参考 R20 的参数结构

虽然尺寸不同，但 `base_link → laser_link → imu_link → camera_link` 的 tf 树结构、关节定义方式可以直接借鉴。

### 7.2 Nav2 参数可参考但需重调

R20 是四驱/麦轮，本车是两驱差速。`diff_drive_controller` 参数（轮距、轮径、最大速度）**必须按本车改**：

| 参数 | R20（参考） | 本车 |
|---|---|---|
| `wheel_separation` | 0.20~0.25 | **0.162（待实测）** |
| `wheel_radius` | 0.065 | 0.0325（65mm 直径） |
| `max_linear_vel` | 0.5 | **0.6** |
| `max_angular_vel` | 2.0 | **3.0** |

### 7.3 语音交互设计可借鉴（实现不可借鉴）

R20 的语音流程值得学：
```
唤醒 → 提示音 → 听指令 → 执行 → TTS 回应 → 回到监听
```
这个"对话状态机"的设计与本项目一致，只是底层从"讯飞模块串口"换成"esp-sr + I2S"。
