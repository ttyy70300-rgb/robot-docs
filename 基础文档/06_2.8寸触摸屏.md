# 设备说明：2.8 寸 SPI 触摸屏（QD-TFT2803 / MSP2807）

> 项目：ESP32-S3 两轮差速 ROS2 智能小车
> 文档版本：**v1.0**　｜　正式发布版
> 生成日期：2026-11-07
> 资料目录：`6-触摸屏2.8寸/`

---

## 1. 设备概述

| 项目 | 内容 |
|---|---|
| 屏型号 | **QD-TFT2803**（模组 MSP2807-2.8-SPI） |
| 尺寸 | 2.8 英寸 |
| 分辨率 | **240 × 320**（竖屏），RGB565 |
| 显示驱动 IC | **ILI9341** |
| 触摸 IC | **XPT2046**（电阻式，SPI） |
| 接口 | 14P 单排针（SPI） |
| 背光 | 4 × 白光 LED，**高电平使能** |
| 板载附加 | Micro SD 卡座（SPI） |
| 供电 | 5V 或 3.3V（J1 跳线选择） |

> 本屏是**状态显示 + 本地操作**的人机界面，不承担实时控制职责。

## 2. 关键参数

### 2.1 显示参数

| 项目 | 数值 |
|---|---|
| 显示区 | 43.2 × 57.6 mm |
| 色彩 | 65K / 262K（RGB565 / RGB666） |
| 视角 | 6 点钟方向（TN） |
| 对比度 | 500:1（典型） |
| 亮度 | 200 cd/m²（典型） |
| 响应时间 | 25 ms |

### 2.2 电气参数

| 项目 | 最小 | 典型 | 最大 | 单位 |
|---|---|---|---|---|
| 逻辑电源 VDD | 2.5 | 3.3 | 3.6 | V |
| 背光电源 | — | 5.0 | — | V |
| 背光电流 | — | 60 | 80 | mA |
| 逻辑电流 | — | 5 | — | mA |
| **SPI 时钟（ILI9341 写）** | — | 40 | **≤ 80** | MHz（见注） |
| 工作温度 | -20 | — | 70 | ℃ |

> **SPI 时钟说明**：ILI9341 数据手册标称写周期 100ns（≈10MHz），但实测多数模组可稳定跑到 40MHz。**建议起始 26MHz，稳定后再提**。ESP32-S3 的 SPI2 可到 80MHz，但排线长时会误码。

### 2.3 供电选择（J1 跳线）

| 输入 VCC | J1 | 说明 |
|---|---|---|
| **5V** | **断开** | 板载 XC6206 LDO 降到 3.3V |
| 3.3V | 短接 | 直通，省 LDO 损耗 |

> 本项目由 TB6612 的 5V 供电 → **J1 保持断开**。

## 3. 接口定义

### 3.1 14P 排针（J2）

| Pin | 丝印 | 功能 | ESP32 方向 |
|---|---|---|---|
| 1 | **GND** | 地 | — |
| 2 | **RESET** | LCD 复位（低有效） | 输出 |
| 3 | **SCL** | SPI 时钟 | 输出 |
| 4 | **RS** | 数据/命令选择（DC） | 输出 |
| 5 | **CS** | LCD 片选（低有效） | 输出 |
| 6 | **SDA** | SPI MOSI | 输出 |
| 7 | **SDO** | SPI MISO | 输入 |
| 8 | **GND** | 地 | — |
| 9 | **VDD** | 3.3V 逻辑电源 | — |
| 10 | **LEDA** | 背光阳极 | — |
| 11 | **LEDK1** | 背光阴极 1 | — |
| 12 | **LEDK2** | 背光阴极 2 | — |
| 13 | **LEDK3** | 背光阴极 3 | — |
| 14 | **LEDK4** | 背光阴极 4 | — |

> **LEDK1~4 内部并联**，接背光控制三极管（S8050）集电极；LEDA 接 5V。
> 板上 `TFT_BL` 高电平 → 三极管导通 → 背光亮。

### 3.2 触摸部分（XPT2046，独立 4P）

| 信号 | 说明 |
|---|---|
| **TP_CLK** | SPI 时钟（**与 LCD 共用 SCL**） |
| **TP_DIN** | 触摸命令输入（**与 LCD 共用 MOSI**） |
| **TP_OUT** | 触摸数据输出（**与 LCD 共用 MISO**） |
| **TP_CS** | 触摸片选（独立） |
| **TP_IRQ** | 触摸中断（按下为低，可轮询不用） |

> **关键**：触摸与 LCD **共用同一条 SPI 总线**，靠各自的 CS 分时复用。

### 3.3 SD 卡座（预留，本项目不用）

`SD_CS / SD_MOSI / SD_MISO / SD_CLK` —— 与 LCD 共用 SPI，独立 CS。

## 4. 接线方案（ESP32-S3）

| 屏引脚 | ESP32 GPIO | 说明 |
|---|---|---|
| GND | GND | — |
| VDD | 3V3 | 逻辑电源 |
| LEDA | **5V** | 背光阳极（经板上三极管） |
| RESET | GPIO42 | 独立控制（不复用 EN） |
| SCL | GPIO13 | SPI2 SCLK |
| RS(DC) | GPIO39 | 命令/数据 |
| CS | GPIO38 | LCD 片选 |
| SDA(MOSI) | GPIO14 | SPI2 MOSI |
| SDO(MISO) | GPIO40 | SPI2 MISO（触摸也用） |
| TP_CS | GPIO21 | 触摸片选 |
| TP_IRQ | GPIO2 | 触摸中断（可轮询不用） |
| TFT_BL | GPIO41 | 背光 PWM 调光（也可接 3.3V 常亮） |

**SPI 总线分配**

| 信号 | GPIO | 备注 |
|---|---|---|
| SCLK | 13 | 共用 |
| MOSI | 14 | 共用 |
| MISO | 40 | 共用（LCD 只写，MISO 给触摸） |
| CS_LCD | 38 | — |
| CS_TP | 21 | — |
| DC | 39 | — |
| RST | 42 | — |
| BL | 41 | LEDC PWM |

> ⚠️ **GPIO35/36/37 绝对不能用**（八线 PSRAM）。上表已避开。

## 5. 软件抽象设计（`ui` 模块）

### 5.1 模块职责与边界

**负责**：LCD 初始化、LVGL 移植、触摸读取与校准、界面状态刷新、背光控制。
**不负责**：业务逻辑（由 `sys` 提供状态，`ui` 只渲染）。

### 5.2 技术选型（v2 · Arduino 栈）

| 层 | 选型 | 理由 |
|---|---|---|
| LCD 驱动 | **TFT_eSPI**（备选 **LovyanGFX**） | Arduino 生态最成熟；TFT_eSPI 需改 `User_Setup.h`，LovyanGFX 运行时可配 |
| 触摸驱动 | **XPT2046_Touchscreen** 或 LovyanGFX 内置 | 共用 SPI，独立 CS |
| GUI 框架 | **LVGL 9.x** | 与 TFT_eSPI / LovyanGFX 都有官方对接示例 |
| 中文字体 | LVGL 内置 `source_han_sans_sc_16_cjk` 或自制字库 | 存 SPIFFS / LittleFS |
| 背光 | `ledcAttach()` + `ledcWrite()`（core 3.x） | 5kHz PWM 调光 |

> ⚠️ **TFT_eSPI 的坑**：它靠 `User_Setup.h` 里的 `#define` 决定驱动和引脚，是**编译期全局配置**。
> 本项目板 1 的 SPI 总线**只给屏幕用**（触摸共用），所以不会和其他设备冲突。
> 如果你更想运行时可配（比如后期换屏），直接上 **LovyanGFX**，API 更干净。

### 5.9 初始化流程

```c
esp_err_t ui_init(void)
{
    /* 1. LCD（TFT_eSPI 已在 User_Setup.h 里绑好引脚） */
    s_tft.init();
    s_tft.setRotation(0);                 /* 0=竖屏，1/3=横屏 */
    s_tft.fillScreen(TFT_BLACK);
    s_tft.invertDisplay(true);            /* 多数模组需要反色，花屏时先改这里 */

    /* 2. 触摸（与 LCD 共用 SPI，独立 CS） */
    s_touch.begin();
    s_touch.setRotation(0);
    s_touch.setThreshold(400);            /* 压力门限，太低会漂 */

    /* 3. 背光 */
    ledcAttach(UI_LCD_BL_PIN, UI_BL_LEDC_FREQ_HZ, UI_BL_LEDC_RES_BITS);
    ui_set_backlight(UI_BL_DEFAULT_PCT);

    /* 4. LVGL */
    lv_init();
    /* ... lv_disp_draw_buf / lv_disp_drv_register（flush_cb 里调 s_tft.pushColors）
           lv_indev_drv_register（read_cb 里读 s_touch.getPoint）... */

    s_lvgl_mutex = xSemaphoreCreateMutex();
    return ESP_OK;
}
```

**注意点（Arduino 栈特有）**

| 点 | 说明 |
|---|---|
| `invertDisplay` | 花屏/色反的第一嫌疑人 |
| `setRotation` | LCD 与触摸必须**设成同一个值**，否则点击位置错位 |
| `setThreshold` | 电阻屏压力门限，太低会自己乱点，太高点不动 |
| `pushColors` | LVGL flush 回调里用它，比逐像素快 10 倍以上 |
| SPI 时钟 | 26MHz 起步；排线长时降到 20MHz 更稳 |

### 5.10 任务

| 任务 | 核心 | 优先级 | 栈 | 周期 | 职责 |
|---|---|---|---|---|---|
| `task_ui` | 0 | 4 | 8192 | 33ms | `lv_timer_handler()` + 触摸读取 |

```c
void ui_task(void *arg)
{
    TickType_t last = xTaskGetTickCount();
    while (1) {
        ui_lock();
        lv_timer_handler();
        ui_unlock();

        /* 触摸 -> LVGL */
        ui_touch_t t;
        if (ui_read_touch(&t)) {
            ui_lock();
            /* 注入 LVGL indev */
            ui_unlock();
        }
        vTaskDelayUntil(&last, pdMS_TO_TICKS(UI_REFRESH_PERIOD_MS));
    }
}
```

> ⚠️ **LVGL 非线程安全**。任何跨任务操作 UI（如 `ui_toast`）必须 `ui_lock()/ui_unlock()` 包裹。

### 6.2 主界面元素

| 区域 | 内容 | 刷新率 |
|---|---|---|
| 状态栏 | WiFi 信号、电量、雷达/摄像头图标 | 1Hz |

## 7. 错误处理与自检

| 检查 | 方法 | 处理 |
|---|---|---|
| LCD 无响应 | 读 ID（0x04 命令返回 0x9341） | 上报故障，UI 降级为纯串口 |
| 触摸无响应 | 读 XPT2046 ID（0x00/0x90） | 禁用触摸，仅显示 |
| 花屏/色偏 | 检查 `invert_color` 与 `rgb_ele_order` | 四个组合逐个试 |
| 白屏 | 背光未开 / RST 时序 | 检查 `TFT_BL` 电平 |
| 刷屏慢 | SPI 时钟过低 / 无 DMA | 提高 pclk，启用 DMA |
| 触摸坐标错乱 | 未校准 / swap_xy 设错 | 跑 `ui_touch_calibrate()` |

### 7.1 触摸校准

电阻屏必须校准一次，结果存 NVS：

```c
esp_err_t ui_touch_calibrate(void)
{
    /* 依次在四角画十字，记录原始 ADC 值 */
    /* 计算 x_min/x_max/y_min/y_max，写入 NVS（Preferences 库） */
    /* 若方向反了，改 s_touch.setRotation() 或交换 x/y 映射 */
}
```

## 10. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 全白 | 背光没开 | `TFT_BL` 拉高 |
| 全黑但有背光 | 初始化失败 | 查 SPI 接线、CS/DC |
| 颜色反了 | 需要 invert | `s_tft.invertDisplay(true)` |
| 红蓝互换 | BGR/RGB 顺序 | TFT_eSPI 改 `TFT_RGB_ORDER`，或 LovyanGFX 改 `rgb_order` |
| 图像偏移 | 未设 gap | LovyanGFX 调 `offset_xy` |
| 触摸无反应 | 片选/时钟共用时序冲突 | 降低 SPI 时钟，检查 CS 建立时间 |
| 屏幕干扰雷达 | SPI 高频辐射 | 缩短排线、加磁环、降时钟 |
