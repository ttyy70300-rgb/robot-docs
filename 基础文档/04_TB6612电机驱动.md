## 4. 控制真值表（TB6612FNG）

| AIN1 | AIN2 | PWMA | STBY | 电机状态 |
|---|---|---|---|---|
| H | H | 任意 | H | **短路刹车**（Brake） |
| L | H | H | H | **反转**（CCW） |
| L | H | L | H | 短路刹车 |
| H | L | H | H | **正转**（CW） |
| H | L | L | H | 短路刹车 |
| L | L | H | H | **自由停车**（Coast，高阻） |
| X | X | X | **L** | **待机**（高阻，最低功耗） |

**要点**

- **PWM 调速接 PWMA，方向接 AIN1/AIN2**，这是"PWM 模式"。若把 PWM 接 IN 脚也能调速，但线性度差。
- **刹车 vs 停车**：`AIN1=AIN2=H` 是短路刹车（电机绕组短接，快速停）；`AIN1=AIN2=L` 是自由滑行。**停车建议用刹车**，防止惯性滑行影响里程计。
- **STBY 必须为高**才能工作。

### 4.1 ⚠️ STBY 的语义（v1.0 定案）

| 项 | 结论 |
|---|---|
| 接线 | **GPIO47，受软件控制**（不是接 3.3V 常开） |
| 拉低的效果 | **高阻滑行（coast）**，不是刹车 |
| 用途 | ① 上电初始化前的安全态 ② 故障时切断输出 ③ OTA 期间断电 |
| **不可用于急停** | ❌ 见下 |

**为什么 STBY 不能做急停**

看真值表最后一行：`STBY = L` 时电机进入**待机（高阻）**，绕组不短接，车会**靠惯性继续滑行**。

对一个可能以 0.6 m/s 行驶、总重 1kg 的小车，滑行意味着：

```
0.6 m/s 自由滑行，滚动阻力约 0.05g
→ 停止距离约 0.37 m，耗时约 1.2 s
```

这 1.2 秒里车是**不受控制的**。而如果目标是"前面有人/有桌腿"，这 37cm 就是撞上去的距离。

**正确的急停动作序列**

```c
void mtr_emergency_stop(uint8_t ch)
{
    /* ① 先短路刹车：AIN1=AIN2=H, PWM=0 */
    tb6612_set_dir(ch, TB_DIR_BRAKE);
    tb6612_set_pwm(ch, 0);

    /* ② 再拉低 STBY 切断输出（防止 PWM 引脚悬空导致意外转动） */
    /*    注意：这一步在刹车之后，顺序不能反 */
    tb6612_set_standby(false);
}
```

> **顺序不能颠倒**：先 `STBY=L` 再设 AIN 是无效的——待机状态下 H 桥已断开，AIN 电平不起作用，电机只会滑行。
>
> **复位的顺序相反**：先 `STBY=H` 让 H 桥就绪，再设方向与 PWM。

**刹车 vs 滑行的停车距离对比（估算）**

| 方式 | 停止距离 @0.6 m/s | 对里程计的影响 |
|---|---|---|
| 短路刹车 | ~0.05 m | 可预测，轮子立即停 |
| 自由滑行 / STBY 拉低 | ~0.37 m | 轮子继续转，编码器继续计数，但车已在"失控"状态 |

## 5. 电压检测（ADC）

```
ADC 引脚电压 = VM / 11
实际电压 = ADC 读数换算值 × 11
```

**分压电路**：R1 = 100kΩ，R2 = 10kΩ（典型值），分压比 1/11。

**ESP32 侧换算**（假设 12dB 衰减，量程 0~3.1V）：

```c
/* ADC 读取 VM 电压 */
float tb6612_read_vm(void)
{
    int raw = adc_oneshot_read(handle, ADC_CHANNEL_X, &val);
    float v_adc = val / 4095.0f * 3.1f;    /* 12dB 衰减 */
    float v_div = v_adc / 0.986f;          /* 校准系数 */
    return v_div * 11.0f;                  /* 还原 VM */
}
```

> ⚠️ **ESP32-S3 用 ADC1（GPIO1~10）**。ADC2（GPIO11~14）在 WiFi 开启时不可用。

> ⚠️ ADC 引脚输出阻抗较高（分压后 9kΩ 左右），ESP32 ADC 要求源阻抗 <10kΩ，**勉强可用但建议加 0.1µF 对地电容**稳定读数。

**用途**：监测电池电压 → 低压告警（<6.4V）→ 限制电机输出。**与 INA226 功能重叠**，二选一即可（INA226 更准，但量程受限，见 09 文档）。

## 6. 电源架构（整车）

```
2S 7.4V 18650 电池组（带保护板）
      │
      ├──(主开关)──► TB6612 VM 输入
      │                   │
      │                   ├──► MOTOR A/B（电机功率）
      │                   │
      │                   └──► 板载稳压
      │                            ├──► 5V/5A  ──┬──► ESP32 主控板 5V0
      │                            │              ├──► 2.8" 屏 VDD
      │                            │              ├──► D6 雷达 5V
      │                            │              └──► 2× SG90 舵机 5V
      │                            │
      │                            └──► 3.3V/0.5A ──► 编码器霍尔 ×2（20mA）
      │
      └──(INA226 支路监测，可选)

```

### 6.1 电流预算

| 负载 | 典型 | 峰值 | 备注 |
|---|---|---|---|
| ESP32-S3（WiFi） | 240 mA | 500 mA | 5V 侧约 120mA（3.3V 折算） |
| 2.8" 屏 + 背光 | 100 mA | 150 mA | 5V |
| D6 雷达 | 240 mA | 800 mA | 5V，峰值在启动瞬间 |
| SG90 ×2 | 120 mA | **1500 mA** | 堵转时 |
| 编码器 ×2 | 20 mA | 30 mA | 3.3V |
| **5V 侧合计** | **~700 mA** | **~3.0 A** | TB6612 5V/5A 够用 |
| 电机 ×2 | 300 mA | 2400 mA | 6V 空载 ~150mA/个 |

### 6.2 关键设计约束

1. **雷达启动瞬间 800mA**，若与舵机同时动作，5V 可能跌落 → 加 470µF 电解 + 0.1µF 陶瓷。
2. **舵机与主控共 5V**：舵机堵转会引起复位 → 建议舵机电源单独走线，或在舵机侧加 1000µF。
3. **电机与逻辑地单点汇合**，避免电机大电流在地线上产生压降干扰编码器。
4. **电机两端各并 0.1µF 陶瓷电容**（抑制换向火花 EMI），否则编码器计数会乱跳。

## 7. 软件抽象设计（`drv` 驱动层）

### 7.1 模块职责与边界

`drv_tb6612` 只负责**引脚级操作**：置方向、写 PWM、读 ADC、置 STBY。
**不含** PID、不含运动学、不含速度换算（那是 `mtr` 模块的事）。

分层：
```
kin (运动学)  →  mtr (闭环)  →  drv_tb6612 (引脚)  →  硬件
```

### 7.2 常量与配置宏

```c
/* drv_tb6612.h */
#define TB_A_PWM_PIN        4
#define TB_A_IN1_PIN        5
#define TB_A_IN2_PIN        6
#define TB_B_PWM_PIN        7
#define TB_B_IN1_PIN        15
#define TB_B_IN2_PIN        16
#define TB_STBY_PIN         47       /* -1 表示硬件常接 3.3V */
#define TB_ADC_PIN          1        /* ADC1_CH0，需在 ADC1 范围 */

#define TB_PWM_FREQ_HZ      20000
#define TB_PWM_RES_BITS     10
#define TB_PWM_MAX          ((1 << TB_PWM_RES_BITS) - 1)

#define TB_ADC_DIVIDER      11.0f    /* VM = ADC × 11 */
#define TB_ADC_ATTEN        ADC_ATTEN_DB_12
#define TB_VM_MIN_MV        6400     /* 2S 低压保护阈值 */
#define TB_VM_MAX_MV        8800     /* 2S 满电 8.4V + 余量 */
```

### 7.3 枚举与状态

```c
typedef enum {
    TB_DIR_COAST = 0,    /* 自由停车 AIN1=0 AIN2=0 */
    TB_DIR_CW,           /* 正转     AIN1=1 AIN2=0 */
    TB_DIR_CCW,          /* 反转     AIN1=0 AIN2=1 */
    TB_DIR_BRAKE,        /* 短路刹车 AIN1=1 AIN2=1 */
} tb_dir_t;

typedef struct {
    uint8_t  inited;
    int16_t  pwm;        /* 当前 PWM -1023~1023 */
    tb_dir_t dir;
    uint32_t vm_mv;      /* 最近一次测得的 VM 电压 */
    uint32_t err_cnt;    /* ADC 读取失败计数 */
} tb_channel_t;
```

### 7.4 全局变量

```c
extern tb_channel_t g_tb[2];      /* [0]=A(左) [1]=B(右)，状态快照 */
extern uint32_t     g_vm_mv;      /* VM 电压，供全局读取 */
```

```c

 * @brief  初始化 TB6612 驱动（GPIO + LEDC + ADC）
```

### 7.8 关键实现片段

```c
esp_err_t tb6612_set(uint8_t ch, int16_t pwm)
{
    if (ch > 1) return ESP_ERR_INVALID_ARG;

    /* 限幅 */
    if (pwm >  TB_PWM_MAX) pwm =  TB_PWM_MAX;
    if (pwm < -TB_PWM_MAX) pwm = -TB_PWM_MAX;

    tb_dir_t dir;
    uint16_t duty;

    if (pwm > 0) {
        dir = TB_DIR_CW;  duty = pwm;
    } else if (pwm < 0) {
        dir = TB_DIR_CCW; duty = -pwm;
    } else {
        dir = TB_DIR_BRAKE; duty = 0;     /* 0 用刹车，不用滑行 */
    }

    return tb6612_set_raw(ch, dir, duty);
}

esp_err_t tb6612_set_raw(uint8_t ch, tb_dir_t dir, uint16_t duty)
{
    const int in1 = (ch == 0) ? TB_A_IN1_PIN : TB_B_IN1_PIN;
    const int in2 = (ch == 0) ? TB_A_IN2_PIN : TB_B_IN2_PIN;

    switch (dir) {
    case TB_DIR_CW:    digitalWrite(in1, HIGH); digitalWrite(in2, LOW);  break;
    case TB_DIR_CCW:   digitalWrite(in1, LOW);  digitalWrite(in2, HIGH); break;
    case TB_DIR_BRAKE: digitalWrite(in1, HIGH); digitalWrite(in2, HIGH); break;
    case TB_DIR_COAST: digitalWrite(in1, LOW);  digitalWrite(in2, LOW);  break;
    }
    ledcWrite(s_pwm_ch[ch], duty);
    return ESP_OK;
}
```

## 8. 错误处理与自检

| 检查 | 方法 | 处理 |
|---|---|---|
| VM 过压 | ADC > 8.8V | 禁用电机，上报故障 |
| VM 欠压 | ADC < 6.4V | 限速 50%，屏幕告警 |
| ADC 异常 | 连续 5 次读数超范围 | 置 `err_cnt`，改用固定估算 |
| STBY 未使能 | 初始化时检查 | 强制拉高并告警 |
| 电机堵转 | 由 `mtr` 模块判定 | 调 `tb6612_brake()` |

## 10. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 电机不转 | STBY 为低 | 接 3.3V 或拉高 GPIO |
| 电机转但无力 | PWM 频率过高或占空比不足 | 检查 20kHz 配置 |
| 一给 PWM 就复位 | 电源跌落 / 地线干扰 | 加电容、单点接地 |
| 编码器计数乱跳 | 电机换向 EMI | 电机端并 0.1µF |
| 电机方向相反 | 线序或镜像安装 | 代码里取反，别改线 |
| 板子发烫 | 堵转或电流过大 | 检查机械阻力 |
| 接电瞬间烧毁 | 电源反接 | **接线前万用表核对** |
