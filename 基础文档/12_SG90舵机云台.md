## 3. 接口定义

### 3.1 线序（3P 杜邦）

| 线色 | 功能 | 接 ESP32 |
|---|---|---|
| **棕（或黑）** | GND | GND |
| **红** | VCC | **5V**（独立供电，不接 3.3V） |
| **橙（或黄/白）** | PWM 信号 | GPIO（LEDC 输出） |

> ⚠️ **不要接 3.3V**：SG90 在 3.3V 下扭矩大幅下降且可能不动作。
> ⚠️ 不同批次线色可能不同，**以"棕-红-橙 = GND-VCC-SIG"为准，接前用万用表确认**。

### 3.2 PWM 信号规格

| 参数 | 值 |
|---|---|
| 周期 | **20 ms（50 Hz）** |
| 脉宽范围 | **500 ~ 2500 µs**（对应 0° ~ 180°） |
| 中位 | **1500 µs**（90°） |
| 有效分辨率 | 约 1 µs ≈ 0.09° |
| 电平 | 3.3V（TTL 兼容） |

**角度 ↔ 脉宽换算**

```
pulse_us = 500 + angle_deg × (2500 - 500) / 180
         = 500 + angle_deg × 11.111
```

| 角度 | 脉宽 |
|---|---|
| 0° | 500 µs |
| 45° | 1000 µs |
| 90°（中位） | **1500 µs** |
| 135° | 2000 µs |
| 180° | 2500 µs |

### 3.3 云台机械限位

云台标称"俯仰/横向各 90°"，但**实际可用范围受机械结构限制**：

| 轴 | 建议软件限位 | 说明 |
|---|---|---|
| 水平（Pan） | **-70° ~ +70°** | 留 20° 余量防撞限位 |
| 俯仰（Tilt） | **-30° ~ +60°** | 向下看地面/向上看前方 |

> 上电首次动作前**必须先回中位（1500µs）**，再缓慢移动到目标，避免猛冲撞限位扫齿。

## 4. ESP32 驱动方案（LEDC）

### 4.1 为什么用 LEDC 而不是普通 PWM

ESP32-S3 的 **LEDC 外设**支持硬件生成 50Hz PWM，不占用 CPU，且 8 个通道可独立控制。

**分辨率计算**：
```
LEDC 时钟源 80MHz（APB）
目标 50Hz → 分频后计数频率 = 80MHz / 2^res
要求脉宽分辨率 ≥ 1µs → 计数频率 ≥ 1MHz
2^res ≤ 80 → res ≤ 6.32

取 res = 14 bit（16384 级）时：
  计数频率 = 80MHz / 16384 = 4.88 kHz
  周期 = 16384 / 4.88k = 3.36s ❌ 不对
```

**正确算法**：
```
LEDC 定时器：freq = 50Hz，duty_resolution = 14 bit
  duty = pulse_us / 20000 × 2^14
  1500µs → 1500/20000 × 16384 = 1229
  500µs  → 410
  2500µs → 2048
```

> 14 bit 下每级对应 20000/16384 = **1.22 µs**，满足 1µs 需求。

### 4.2 接线

| 舵机 | 信号线 | ESP32 GPIO |
|---|---|---|
| 水平（Pan） | 橙 | **GPIO11** |
| 俯仰（Tilt） | 橙 | **GPIO12** |
| 电源（红） | — | **5V（独立走线，加 1000µF）** |
| 地（棕） | — | GND（与主控共地） |

## 5. 软件抽象设计（`srv` 模块）

### 5.1 模块职责与边界

**负责**：LEDC 初始化、角度→脉宽换算、平滑运动（梯形速度）、限位保护、回中、慢启动。
**不负责**：目标角度决策（上位机或 `sys` 模块给）。

### 5.2 常量与配置宏

```c
/* srv_cfg.h */
#define SRV_COUNT               2

/* 通道定义 */
#define SRV_PAN_IDX             0
#define SRV_TILT_IDX            1

#define SRV_PAN_PIN             11
#define SRV_TILT_PIN            12

/* LEDC（Arduino core 3.x：按引脚号操作） */
#define SRV_LEDC_FREQ_HZ        50
#define SRV_LEDC_RES_BITS       14
#define SRV_LEDC_PERIOD_US      20000

/* 脉宽范围 */
#define SRV_PULSE_MIN_US        500
#define SRV_PULSE_MAX_US        2500
#define SRV_PULSE_MID_US        1500

/* 机械限位（度，相对中位） */
#define SRV_PAN_MIN_DEG         (-70.0f)
#define SRV_PAN_MAX_DEG         (70.0f)
#define SRV_TILT_MIN_DEG        (-30.0f)
#define SRV_TILT_MAX_DEG        (60.0f)

/* 运动参数 */
#define SRV_SPEED_DPS           60.0f      /* 最大角速度 °/s */
#define SRV_ACCEL_DPS2          120.0f     /* 加速度 °/s² */
#define SRV_UPDATE_MS           20         /* 50Hz 更新 */

/* 安全 */
#define SRV_BACKLASH_DEG        2.0f       /* 回差补偿 */
#define SRV_SETTLE_MS           200        /* 到位稳定时间 */
```

### 5.3 数据结构

### 5.8 关键实现

```c
static inline uint32_t srv_deg_to_duty(float deg)
{
    /* deg: -90 ~ +90（相对中位），映射到 500~2500us */
    float pulse_us = SRV_PULSE_MID_US + deg * (SRV_PULSE_MAX_US - SRV_PULSE_MIN_US) / 180.0f;
    if (pulse_us < SRV_PULSE_MIN_US) pulse_us = SRV_PULSE_MIN_US;
    if (pulse_us > SRV_PULSE_MAX_US) pulse_us = SRV_PULSE_MAX_US;
    return (uint32_t)(pulse_us / SRV_LEDC_PERIOD_US * (1 << SRV_LEDC_RES_BITS));
}

esp_err_t srv_init(void)
{
    for (int i = 0; i < SRV_COUNT; i++) {
        /* Arduino core 3.x：一步绑定引脚/频率/分辨率 */
        if (!ledcAttach(s_ch[i].gpio, SRV_LEDC_FREQ_HZ, SRV_LEDC_RES_BITS)) {
            ESP_LOGE(TAG, "ledcAttach failed on GPIO%d", s_ch[i].gpio);
            return ESP_FAIL;
        }
        ledcWrite(s_ch[i].gpio, srv_deg_to_duty(0));   /* 中位 */
        s_ch[i].cur_deg = 0;
        s_ch[i].tgt_deg = 0;
        s_ch[i].enabled = true;
    }

    vTaskDelay(pdMS_TO_TICKS(SRV_SETTLE_MS));   /* 等舵机稳定在中位 */
    ESP_LOGI(TAG, "servo init ok, centered");
    return ESP_OK;
}
```

### 5.9 平滑运动（梯形速度）

```c
void task_srv(void *arg)
{
    TickType_t last = xTaskGetTickCount();
    const float dt = SRV_UPDATE_MS / 1000.0f;

    while (1) {
        g_srv.moving = false;
        for (int i = 0; i < SRV_COUNT; i++) {
            srv_ch_t *c = &s_ch[i];
            if (!c->enabled) continue;

            float err = c->tgt_deg - c->cur_deg;
            if (fabsf(err) < 0.5f) { c->vel_dps = 0; continue; }

            /* 加速/减速 */
            float dir = (err > 0) ? 1.0f : -1.0f;
            float v_max = sqrtf(2 * SRV_ACCEL_DPS2 * fabsf(err));
            if (v_max > SRV_SPEED_DPS) v_max = SRV_SPEED_DPS;

            c->vel_dps += dir * SRV_ACCEL_DPS2 * dt;
            if (c->vel_dps >  v_max) c->vel_dps =  v_max;
            if (c->vel_dps < -v_max) c->vel_dps = -v_max;

            c->cur_deg += c->vel_dps * dt;
            if (fabsf(c->tgt_deg - c->cur_deg) < fabsf(c->vel_dps * dt)) {
                c->cur_deg = c->tgt_deg;
            }

            /* 限位 */
            if (c->cur_deg < c->min_deg) c->cur_deg = c->min_deg;
            if (c->cur_deg > c->max_deg) c->cur_deg = c->max_deg;

            ledcWrite(c->gpio, srv_deg_to_duty(c->cur_deg));
            g_srv.moving = true;
        }
        vTaskDelayUntil(&last, pdMS_TO_TICKS(SRV_UPDATE_MS));
    }
}
```

|---|---|---|---|---|---|
| `task_srv` | 1 | 8 | 3072 | 20 ms | 平滑插值 → 更新 PWM |

## 6. 与摄像头的机械配合

### 6.1 云台负载

| 负载 | 重量 | 是否可行 |
|---|---|---|
| OV2640 模组（裸板） | ~5 g | ✅ |
| OV2640 + 亚克力支架 | ~15 g | ✅ |
| 金属云台 + 摄像头 | ~40 g | ⚠️ 接近极限 |
| 摄像头 + 补光灯 | >60 g | ❌ 会抖动/扫齿 |

> SG90 扭矩 1.2 kg·cm，在 2cm 力臂下只能提 600g。负载越重，**响应越慢且易抖动**。

### 6.2 安装要点

1. **重心靠近舵机轴心**，减小惯性力矩。
2. 排线**留足余量**，转动时不能拉扯。
3. **先手动转到极限位置确认不撞**，再上电。
4. 上电前把云台放在**中位附近**，避免猛冲。

## 7. 电源设计（重要）

舵机与主控共 5V 是**复位的主要诱因**。

### 7.1 问题

```
舵机堵转 750mA × 2 = 1.5A 瞬间拉载
  → 5V 跌落 0.3~0.8V
  → ESP32 欠压复位
  → WiFi 断连
```

### 7.2 解决方案（按优先级）

| 方案 | 成本 | 效果 |
|---|---|---|
| **舵机侧加 1000µF 电解 + 0.1µF 陶瓷** | 低 | ★★★★ 吸收瞬态 |
| **舵机电源单独走线**（不与其他共线） | 低 | ★★★★ 隔离压降 |
| 用独立 5V UBEC 给舵机 | 中 | ★★★★★ 彻底隔离 |
| 软件限加速度（`SRV_ACCEL_DPS2` 降低） | 零 | ★★★ 减小冲击电流 |

> **本项目建议：前两条必做，第三条可选。**

## 8. 错误处理与自检

| 检查 | 方法 | 处理 |
|---|---|---|
| 上电位置 | 无法软件检测（无反馈） | 强制回中位后再动 |
| 堵转 | 无电流检测，无法判断 | 限加速度 + 限位 + 超时 |
| 运动超时 | 目标 3s 未到位（理论上限） | 停止输出，上报异常 |
| 角度越界 | `srv_set_angle` 入参检查 | 自动 clamp 到限位 |

### 8.1 扫齿预防（软件层）

```c
/* 三条铁律 */
1. 上电先回中位，等 200ms 稳定
2. 所有运动走梯形速度，禁止直接跳变
3. 软限位比机械限位小 15~20°
```

**下行帧 `0x51`（云台）**

| 字段 | 类型 | 单位 | 说明 |

| `pan_deg` | int16 | 0.01° | 水平角，-7000~7000 |

## 11. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 舵机不转 | 接了 3.3V / 信号线接错 | 接 5V，核对线序 |
| 抖动/嗡嗡响 | 电源纹波 / 负载过重 | 加电容，减重 |
| 转到极限卡住 | 软限位没设 | 设 `SRV_*_MIN/MAX_DEG` |
| 扫齿 | 手掰 / 撞限位 | **严禁手掰**，加软限位 |
| 一动作就复位 | 电流冲击 | 加大电容、独立供电 |
| 角度不准 | 开环 + 回差 | 加回差补偿，或换数字舵机 |
| 两个舵机互相干扰 | 共用电源线 | 分开走线，星型接地 |
